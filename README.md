## 👋 About me

I’m **Farid Ahmad Khan**, a **Python developer**. Python is the main language I work with, and I use it to build web applications, backend services, automation tools, and integrations, taking ideas from a rough sketch to something people can actually use.

I can build **any kind of Telegram bot for any service** — from simple assistants to full business bots with payments, databases, and API integrations.

I’m not just writing code: I also deploy and run what I build. I work with **Render, Railway, VPS servers, and other hosting providers**, and I use **Supabase** as a backend for databases and authentication.

Right now I’m **strengthening my Python fundamentals** and moving into **data science with Python**, learning the libraries used for data analysis and machine learning.
